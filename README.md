# 低碳校园资源循环流转桌面系统

面向高校校园的闲置物品流转桌面应用。学生可以发布、检索、收藏闲置物品并完成流转与互评；管理员维护用户、类别和违规物品。使用 Java、Swing、SQLite，最终打包为可直接运行的 Jar。

## 当前阶段

第 1/2 周（迭代 1）只做需求与设计：需求规格、分工、模块接口、数据库表设计、UML。业务代码和界面从第 3 周开始。
