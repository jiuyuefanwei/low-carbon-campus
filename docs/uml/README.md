## 2. 类图说明

类图主要描述系统的静态结构，包括用户、物品类别、闲置物品、收藏、流转记录和评价六个核心实体类，以及对应的数据访问层和业务逻辑层。统计服务待业务规则完善后补入类图。

通过类之间的关联关系，明确用户与物品、物品与流转记录、流转记录与评价之间的数据关系，为后续 Java 类的设计与实现提供依据。

## 3. 时序图说明

### 3.1 登录时序图

描述用户提交登录信息后，系统通过 UserService 调用 UserDAO 查询用户信息，并完成密码验证和账号状态检查。根据验证结果，系统向用户返回相应的登录提示或进入系统主界面。

### 3.2 发布物品时序图

描述用户在界面填写物品信息并提交后，系统对物品信息进行校验，通过 ItemDAO 将符合要求的物品信息保存至 SQLite 数据库，并向用户反馈发布结果。

### 3.3 成交流转时序图

描述用户发起物品流转请求后，系统在同一事务中创建待处理流转记录，并把物品改为流转处理中。物品所有者接受后，由发起人确认完成；系统再通过事务把流转和物品都改为已完成，并按类别系数写下减排估算值。拒绝或取消后物品回到在架，这条分支见数据库设计，本图只画接受并完成的主路径。

### 3.4 提交评价时序图

描述用户在流转完成后提交评价，系统对流转状态、评价权限及评价内容进行校验。校验通过后，将评价信息保存至数据库，并根据评价结果更新被评价用户的信用分，最后向用户反馈评价提交结果。

## 4. 设计说明

本阶段 UML 图主要依据当前数据库设计及系统需求进行绘制，重点体现系统核心实体关系、分层结构和主要业务交互过程。后续开发过程中，将根据实际功能实现情况对类结构和业务流程进行调整与完善。
