# 模块与接口

> 由业务与测试负责人主写。

## 1. 模块

| 模块 | 职责 | 不负责 |
| --- | --- | --- |
| 用户 | 注册、登录、角色、信用分 | 界面绘制 |
| 物品 | 发布、修改、下架、检索、收藏 | 成交状态流转 |
| 流转 | 意向、流转记录、成交或交换 | 信用计算规则的展示 |
| 评价 | 互评、信用分更新 | 物品发布 |
| 统计 | 流转数量、减排估算、CSV 导出 | 原始数据录入 |
| 界面 | Swing 展示与事件 | 业务规则本身 |
| 数据访问 | JDBC 读写 SQLite | 业务判断 |

### 2. 模块接口
（每个模块列出对其他模块提供的操作，例如「按关键词检索在架物品」。）
#### 用户模块
- register：注册新用户
- login：登录身份校验
- getUserById：根据用户ID查询用户信息
- updateUserInfo：修改用户基础资料
- updateCreditScore：更新用户信用分值

#### 物品模块
- publishItem：发布闲置物品
- updateItem：修改已发布物品信息
- withdrawItem：下架物品
- searchItem：按关键词、分类、价格区间检索物品
- collectItem / cancelCollect：收藏 / 取消收藏物品
- listMyItem：查看自己发布的所有物品
- listMyCollect：查看自己收藏的物品

#### 流转模块
- createTransfer：发起流转意向
- confirmTransfer：卖家确认意向，标记成交
- cancelTransfer：取消流转意向
- listMyTransfer：查询和自己相关的流转记录

#### 评价模块
- addComment：提交互评内容与分数
- getCommentByTransferId：查询某条流转下的全部评价

#### 统计模块
- getTotalTransferCount：获取平台总成交数量
- getUserStats：获取个人流转统计数据
- calcCarbonSave：根据成交数量估算碳减排量
- exportTransferToCSV：将流转记录导出为CSV文件

### 3. 业务规则与非法输入
（价格、空名称、重复登录、评价时机、下架权限等。）
#### 用户业务规则
- 用户名唯一，不可重复注册；用户名、密码不能为空
- 密码加密存储，密码不匹配则登录失败
- 用户角色仅支持 student、admin，不允许其他角色值
- 信用分下限为0，不允许出现负分

#### 物品业务规则
- 物品名称不能为空，物品价格不能为负数
- 下架权限：仅物品发布者本人、管理员可以执行下架
- 物品状态分为：待流转、已成交、已下架；已成交物品不能发起新意向
- 同一用户不可重复收藏同一个物品

#### 流转业务规则
- 一件物品同一时刻只能存在一条有效的流转意向
- 只有卖家可以确认意向；买家、卖家、管理员都可以取消意向
- 意向确认成交后，物品自动切换为【已成交】状态

#### 评价业务规则
- 仅流转状态为【已成交】时，才开放评价入口
- 一条流转记录，买家、卖家各自只能评价一次，禁止重复评价
- 评分合法区间：1~5分，0分、6分等属于非法输入

#### 通用约束
- 多表同步更新（成交确认、提交评价）必须使用数据库事务
- 所有操作前置权限校验，拦截越权访问

### 4. 后续测试点
（列出第 3/4 周要覆盖的核心用例，本阶段不写测试代码。）
#### 用户模块测试点
1. 使用已存在的用户名注册，预期注册失败
2. 账号密码不匹配，登录校验失败
3. 学生账号尝试管理员专属操作，被权限拦截
4. 信用分为0时，继续扣减分数，操作失败

#### 物品模块测试点
1. 输入负数价格，参数校验失败
2. 非物品发布者尝试下架他人物品，权限拦截
3. 关键词、分类、价格区间组合检索，校验筛选结果正确性
4. 对已经收藏的物品再次收藏，操作失败

#### 流转模块测试点
1. 物品状态为已成交，再次发起流转意向，失败
2. 无关第三方用户尝试确认流转意向，权限拦截
3. 意向取消后，物品状态恢复为待流转

#### 评价模块测试点
1. 流转还未成交，尝试提交评价，直接拦截
2. 针对同一条流转记录，重复提交评价，拦截
3. 输入0或者6这类超出范围的分数，校验失败

#### 统计模块测试点
1. 新增成交记录后，统计总数同步更新
2. 导出CSV时传入非法路径，程序捕获异常
