# 需求规格

> 迭代 1 文档。组长汇总，组员补充后各自提交修改。

## 1. 项目概述

（背景、目标用户、系统形态：Java 桌面应用。）

## 2. 用户角色

- 普通学生用户
- 系统管理员

## 3. 功能需求

### 3.1 用户账号

注册、登录、密码加密存储、角色区分、输入校验。

### 3.2 闲置物品发布

发布、修改、下架。字段：名称、分类、描述、期望交换或售卖价格、状态、标签。

### 3.3 检索与收藏

按分类、关键词、价格区间筛选，模糊搜索，收藏。

### 3.4 供需沟通与流转

发起意向、生成流转记录、记录成交或交换状态。

### 3.5 评价与信用

流转完成后互评，维护并展示信用分数。

### 3.6 数据统计

分类流转数量、低碳减排估算、导出 CSV。

### 3.7 管理员后台

用户管理、违规物品下架、类别维护、全平台统计。

## 4. 非功能需求

- 非法输入校验与异常处理
- 关键操作日志
- 业务数据持久化到 SQLite
- 最终交付可双击运行的 Jar

## 5. 不做或后置

- 第 1/2 周不实现业务代码和 Swing 界面
- 图片存储、备份恢复、智能推荐为选做
